The CV page is live and working from the built-in content. To edit it from this page, connect a Firebase project - it takes about five minutes and the free tier is more than enough.

  1. Go to console.firebase.google.com and create a project (e.g. indika-portfolio).
  2. Build → Firestore Database → Create database → Production mode.
  3. Build → Authentication → Get started → enable Email/Password, then Users → Add user → iamarasinghe96@gmail.com with a password you choose.
  4. Project settings → Your apps → Web app → register the app, then copy the firebaseConfig values.
  5. Paste them into cv/firebase-config.js in this repository and commit.
  6. Firestore → Rules → paste the rules below → Publish.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /portfolio/cv {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'iamarasinghe96@gmail.com';
    }
  }
}

Full instructions, including how to publish the first copy of the CV, are in cv/README.md.
